# 날짜·지역 계약 (#1, #2)

날짜 추론의 시계는 KST이며 테스트에서 주입한다. 연도 없는 월일은 현재 연도로 해석하되 12월↔1월만 인접 연도로 보정한다. 10월의 3월 공고를 다음 해로 옮기지 않는다. 명시 연도 우선, 역전 범위는 폐기하고 검토 표시한다. 연도 없는 원문은 확인이 필요한 정보다.

날짜 마감은 KST 당일 23:59:59.999까지 유효하다. 크롤러 저장 경계에서 date-only를 이 timestamp로 변환하며, 원문 timestamp의 offset은 유지한다. 카드와 목록은 현재 시각과 비교한다. 오늘/3일/7일은 KST 오늘/오늘+3/오늘+7 날짜 끝까지이며 상한은 다음 날 00:00 미만이다.

중요: 기존 timestamptz 컬럼에는 원래 date-only였는지 구분하는 메타데이터가 없다. UTC 자정 값을 임의로 date-only로 해석하지 않는다. 운영 데이터 일괄 보정은 원문/snapshot으로 precision을 확인한 dry-run과 별도 승인 후 수행한다. 이 변경은 기존 DB를 수정하지 않는다.

광역 필드는 정식 광역명/약칭의 정확 일치만 신뢰한다. 광주는 광주광역시, 광주시는 광역 문맥 없는 경우 미확정이다. 경기+광주시, 서울+강서구, 부산+강서구는 그대로 유지한다. 강서구·중구·서구만으로 광역을 추론하지 않는다.

광역+세부 검색은 AND이며, 광역 정보 없는 데이터는 특정 지역 필터에서 제외한다. 필터 없는 목록에는 남기되 '지역 확인 필요'로 표시한다. 목록·카운트·지도는 동일한 쿼리 생성기를 쓴다. 지역 선택지는 같은 순수 정규화 함수를 사용한다. 운영 데이터 대량 보정은 별도 승인 대상이다.
