# 무료 탐색 디자인 (#3)

기존 Pretendard/system 글꼴과 밝은 paper/surface, 블루 행동색을 유지한다. 큰 재작성이나 Flutter 전환을 하지 않는다. 이 체크아웃에는 `.agents/skills`와 UI UX Pro Max 스킬이 없으므로 기존 토큰과 저장소의 8px/위계/일관성 규칙으로 설계하고 실제 Chromium으로 검증했다.

- 간격: 새 구조는 8/16/24/32px, 버튼/입력 터치 영역 최소 44px. 본문 line-height 1.6 이상, 제목 24–32px. 포커스 outline 3px 및 4px offset.
- 색: 일반 행동은 기존 `--c-primary`, 본문 `--text-body`, 보조 `--text-muted`. 광고만 기존 warm `--c-sponsor-*`를 사용하고 '광고' 텍스트를 항상 표시한다.
- 구조: 무료 탐색 소개 → 검색/필터 → 결과 수 → 카드/6번째 뒤 광고 1개 → 로딩/재시도/끝 → 이용 안내 footer. 모바일 하단 내비게이션과 CTA를 분리하고 footer 여백을 둔다.
- 모바일: 상단 중복 내비게이션을 숨기고 로고를 한 줄로 유지한다. 필터는 줄바꿈하며 큰 고정 필터가 화면을 가리지 않는다. 카드의 광역·세부 지역, 혜택, 마감, 상세 행동을 유지한다.
- 광고는 일반 카드 순위에 영향을 주지 않는다. SSR에서 슬롯 유무를 결정하여 지연 삽입하지 않는다. 광고 자체의 고정 높이는 강제하지 않아 긴 문구를 잘라 숨기지 않는다.
- 더 보기: 단일 요청 잠금, unmount 취소, 오류/재시도, ID 중복 제거, 마지막 페이지 표시. 필터 URL이 바뀌면 피드와 필터 상태를 새로 만든다.
- 외부 링크는 ↗ 및 새 탭 접근성 문구를 제공한다. 광고 링크와 일반 신청 조건 확인 링크는 문구·색·영역으로 구분한다.

대표 화면은 `docs/qa/`에 있다. 모두 로컬 합성 데이터이며 실제 광고주·이용자·성과가 아니다. 기존 전체 CSS를 새 Tailwind 체계로 변환하지 않았다.
